Official Merchandise

A list of places on where you can find official merchandise for sale. Please consider purchasing it to both support the game (even past its death)!

Please note that this does not include all the merchandise, nor does it include all the places that these can be found. These are just a few of the easiest places to purchase these works and on platforms many use.

Physical Merchandise

Most merchandise is available officially on the Square Enix store, or on Amazon. Please also note that some merchandise may show characters and reference content that is late into the game and could be spoilers.

In addition, a book was released containing the full game story, scrapped content and stories that were not released and included in the original game. Please note that the book is only available in Japanese, and contains massive spoilers for the game. This site covers information about the book after the final chapter.

Square Enix Store (North America) Square Enix Store (United Kingdom) Amazon (United States) The Book (Amazon Japan)
